# AI 压力测试 · Prompt 包（Copy-Paste Ready）

> 用途：按《Ready for Techathon+》推进大纲，把同一组压力测试 Prompt 拿到不同顶级 GenAI 模型（如 HKBU GenAI API 下的各模型、GPT、Claude、Gemini 等）复测对比，结果统一归档到本测试区。
> 使用方法：把下文「共用背景」+ 某一个 Prompt 完整粘贴给目标模型即可；模型输出后按 `模板_归档格式.md` 归档，命名规则 `报告X_<模型名>_<角色>.md`。

## 共用背景（粘贴给任何模型前，先粘这一段）

以下是「Voices of the North（北區之聲）」项目全景与技术链路总纲。团队正在冲刺 Hong Kong Techathon+ 2027（提交截止约 2027-01-11）。

- **项目名称**：北區之聲 (Voices of the North)
- **代码仓库**：https://github.com/buwanmihayou/voices-of-the-north
- **起源与目标赛事**：起源于 Hong Kong Inter-University Generative AI × SDGs Hackathon 2026（Smart Living, Culture & Belonging 赛道），现正迭代冲刺 Hong Kong Techathon+ 2027（HKSTP 与香港各大高校联办，核心考察商业可行性、技术壁垒与真实用户验证）。
- **核心痛点与使命**：随着香港特区政府全力推进「北部都会区（Northern Metropolis）」建设，元朗、粉岭、上水、古洞、新田等新界传统乡村面临大规模城市化与收地转型。高龄原居民长者（75岁+）掌握的粤语/围头话/客家话口述历史面临永久消亡风险。项目利用生成式 AI 与适老化交互，抢救性采集、结构化归档并活化乡村口述历史。
- **商业模式演进（1.0 → 2.0）**：从单纯的 C 端免费公益故事地图（1.0），转型为 B2G（特区政府北都统筹处、乡郊保育资助计划 CCFS、古迹办）+ B2B（新界收地大型地产发展商 ESG 社区文化归档专案）+ B2B2C（高校 Service-Learning 田野采录与中小学研学订阅）的商业闭环（2.0）。
- **技术栈**：FastAPI 后端（server.py），POST /transcribe 核心管道 = Google Cloud STT (language_code="yue-Hant-HK", 词级时间戳+词级置信度) → Gemini 防幻觉结构化提取（formal_text + qa_list，严禁编造）→ 统一 JSON 返回；前端为单页应用（Leaflet + OSM 地图、800 米模糊半径隐私圈、录音抽屉、知情同意弹窗、音文字幕跳轨、村口问答 FAB），390px 移动端优先，Oat × Sage 配色，WCAG 触控标准。
- **团队（5 人）**：Douglas（商业战略/评委反馈/NGO 联络/路演 Deck）、Zheng（后端与部署）、Steven（前端 UI/UX）、Boris（粤语音频测试集与黄金标准校对）、Dat（优先级统筹/用户访谈/知情同意与隐私合规审查）。
- **已知短板（自认）**：零真实用户/社区伙伴（全部故事为 role-play）；隐私层级只有界面无后端；粤语 ASR 依赖 Google Cloud STT 非自研；商业模式模糊；除粤语外三种方言无 ASR 模型；团队全为 ITM 背景。
- **团队红线（方案不得违反，若突破必须论证例外价值）**：不做语音克隆/TTS「复活」逝者；不做社交 feed/点赞/关注；consent-first（知情同意优先）；隐私优先（四级隐私：私人/家人/社区/公开，服务器端过滤）；诚实标注（角色扮演示范故事必须标明，demo-scope 不外推为生产性能）。

## Prompt 1 · 香港科技园（HKSTP）/ 早期 VC 投资人极限压力测试

【角色设定】：你是一位专注于香港早期科技创新与社会影响力投资的资深投资合伙人，拥有多年香港科技园（HKSTP）孵化项目评审与大学创业赛（如 Hong Kong Techathon、TSSSU）评委经验。你的风格犀利客观，重点考察商业闭环、单位经济与技术不可替代性。

【项目背景】：「北区之声（Voices of the North）」利用 Google Cloud STT (yue-Hant-HK) 与 Gemini API，抢救性记录即将面临北部都会区开发的香港新界长者口述历史。功能包括粤语语音转录、音文字幕跳转、带时间戳的问答卡片及 800 米隐私模糊地图。

【任务目标】：请对该项目进行严苛的商业可行性与商业模式压力测试：
1. 需求真伪剖析：长者自主使用 App 是否属于伪需求？如何证明真实的付费客户（如地产商 ESG 部门、政府发展局/乡郊保育基金）存在刚性买单意愿？请给出具体的 TAM/SAM/SOM 测算逻辑。
2. 护城河审查：直接指出仅调用 Google STT 与 Gemini 商业接口的技术脆弱点。如何构建足以申请专利或创新科技基金（ITF）的核心技术壁垒？
3. 单元经济模型（Unit Economics）：评估采录、转录、人工质检单条音频的边际成本 vs B 端/B2G 采购单价，能否支撑自负盈亏？
4. 决战答辩预演：列出 5 个在 Techathon 决赛答辩席上，评委最可能发难的致命问题并给出高分应对策略。

## Prompt 2 · 香港公共政策与北部都会区规划专家视角

【角色设定】：你是香港特区政府城市规划与文化政策专家，深度参与过发展局北部都会区统筹办事处咨询委员会、古物古迹办事处及新界乡郊保育资助计划（CCFS）评审。

【项目背景】：「北区之声」团队希望在北都建设浪潮中保存新界乡村文化记忆，目前正在探索如何获取官方资助及如何合法合规进入乡郊社区。

【任务目标】：请从香港公共政策与社区治理高度，为项目设计官方资源对接与政策合规方案：
1. 资助路径匹配：详述该项目可申请的特区政府资助（如 CCFS、ITF、SIE Fund、赛马会慈善信托），分析各基金的偏好与成功申报要点。
2. 基层治理破冰：新界乡事委员会、原居民村落与外来居民关系复杂。如何通过「关爱队（District Care Teams）」与长者中心建立制度化的信任中介机制？
3. 法律与伦理风控：口述历史极易涉及征地纠纷、历史产权与个人隐私。请依据香港《个人资料（私隐）条例》（PDPO）设计一套数字采录知情同意与敏感言论脱敏 SOP。

## Prompt 3 · 资深语音 AI 首席架构师与粤语 NLP 专家视角

【角色设定】：你是低资源语言语音识别与大语言模型专家，深耕香港繁体粤语 NLP，曾主导研发过企业级转录与时间戳可验证 RAG 检索系统。

【项目背景】：「北区之声」现有技术栈为原生 JS/Leaflet + Python (Google STT yue-Hant-HK + Gemini API)，面临新界乡音（围头话/客家口音）识别率偏低、口语书面化转换生硬等瓶颈。

【任务目标】：请为该项目重构一套具备高技术壁垒的 AI 架构方案：
1. 本土方言识别突破：针对新界原居民混杂的围头话与客家方言词汇，在有限预算下如何运用 Whisper LoRA 微调或音素级（Phoneme-level）对齐提高精度？
2. 毫秒级音文同步：如何实现稳定、防抖动的双向音文字幕寻轨（Audio Seeking）架构？
3. 时空知识图谱（Spatio-Temporal RAG）：如何将长者口述历史与香港历史地图（HK Map Service）数据对齐，构建带地理坐标与时间戳约束的无幻觉问答引擎？
