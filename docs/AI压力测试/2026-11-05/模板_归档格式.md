# 模板 · 压力测试报告归档格式

> 补齐 `00_Prompt包_跨模型复测.md` 第 4 行所引用、但此前缺失的模板文件。
> 命名规则：`报告X_<模型名>_<角色>.md`（X 为 Prompt 编号 1–4）。
> 「本次执行的 Prompt 原文」必须完整粘贴 `00_Prompt包_跨模型复测.md` 的共用背景 + 对应 Prompt；「模型输出全文」原样保留，不改写、不润色。

```markdown
# 报告X · <角色名>视角（模型：<模型名>）

- 执行日期：<YYYY-MM-DD>
- 执行模型：<模型名>
- 项目背景文件：Ready_for_Techathon_plus.txt
- 背景快照（如与背景文件有差异）：<文件路径>
- 事实校验：见 `99_执行说明与跨模型对比.md`

## 本次执行的 Prompt 原文
<「共用背景」+ 完整粘贴 Prompt X>

## 模型输出全文
<原样粘贴，不改写>

## 模型间差异备注（对比其他模型时填写）
- 与 DeepSeek 版报告的差异：
- 更优的点：
- 更差的点：
```

## 铁律

1. **不得伪造其他模型的输出**。只有真实跑过某模型，才能填写该模型的差异对比；未跑过一律写「尚无该模型版本，待复测」。
2. 报告中的事实若与仓库代码不符，须在「事实校验」或输出中显式标注，不得把 `demo-scope` 表述外推为生产性能。
3. 涉及政府资助、法例、市场规模的数字，若未核实来源，标注【待验证】并给出核实路径，不得编造具体金额或成功率。
4. 跨模型复测由团队把 `00_Prompt包_跨模型复测.md` 中的共用背景 + 单个 Prompt 粘贴到目标模型（HKBU GenAI API / GPT / Claude / Gemini）后，按本模板归档，并回填各报告的「模型间差异备注」。
