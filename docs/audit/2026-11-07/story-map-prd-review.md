## 0. 一句话结论

方向是对的：**地图当主视图、故事当一级信息、详情用二级抽屉**。但 PRD 里有三处会「好看但演不出来」——Mapbox 额度、LandsD 历史底图、六类图标——已按「可演示、可回退、守住私隐」的原则改写。现在这版是能直接上台的，不是纸面方案。

## 1. 已经落地的结果

- **地图主视图**：MapLibre GL JS + OpenFreeMap（无 API key），默认展示全部故事点；拖拽/缩放/指南针；2D ⇄ 3D（pitch 55°、建筑挤出，自动飞向故事最密的聚落）。
- **一级信息**：7 类故事图标 + 色板；心情用 12px 角标 + 详情标签双编码；低缩放保留聚合，热力只做底色氛围。
- **二级半拉抽屉**：拖拽手柄、半开/全开、Esc/遮罩关闭并暂停音频；标题区、类型/年代/村落/时长、讲述者、心情标签。
- **录音信息**：自定义播放器，**波形由音档实测振幅解码产生**（RMS＋峰值混合、60 柱双层 SVG，已播放部分着色）；逐字稿真实时间戳作为刻度叠加；点句子、点波形或方向键跳听；段落随播放高亮。音档缺失或浏览器不支持 Web Audio 时自动回退细进度条，**绝不画假波形**。
- **发现路径**：搜索单结果飞至 14 级并高亮，多个结果 fitBounds；类型图例可点选筛选；年代轴按「截至某年」过滤；列表模式保留为降级入口。
- **私隐红线**：只画约 800m 模糊圈（虚线 + 呼吸填充）；`private` 故事不进入地图数据、聚合计数、图例计数与搜索；构建时强制 `radiusM ≥ 100`。
- **三级回退**：MapLibre → Leaflet → 手绘示意图；3D 不可用时按钮禁用并给出原因，不静默失败。
- **数据契约**：新增 `storyType / mood / year`，构建脚本校验枚举与坐标范围；缺字段只警告，兼容旧数据。
- **构建期振幅缓存**：`build_frontend.py` 用标准库 `wave` 实测 PCM，把 60 柱振幅写入 `window.VTN_WAVEFORMS`；运行时不再为画波形下载/解码 4MB WAV。与浏览器 `decodeAudioData` 的结果相关系数 0.918（差异来自重采样）。
- **埋点三事件**：`map.view`（地图浏览时长）、`pin.click`（点位点击率）、`audio.complete` / `audio.progress`（音频完成率）；只记录数值与故事 ID，前端本地缓冲 + `/api/audit` 上报，后端 meta 白名单拒绝自由文本。
- **bbox 视口查询**：`GET /api/stories?bbox=w,s,e,n` 服务端裁剪（授权过滤之后），非法参数 400；前端 `VTN.stories.inBbox()` 与地图 `moveend` 的「视口内 N 则故事」提示。
- **同圈合并**：中心距 ≤ 较大模糊半径即视为同一 800m 圈；点位显示数字角标，点击弹出该圈故事列表再选择，不搬动坐标、不收窄半径。

## 2. 七个判断：同意什么、不同意什么

### 2.1 渲染层：Mapbox GL JS ✗ → MapLibre GL JS + OpenFreeMap ✓

「接 API 烧点没事」不是关键，**演示连续性**才是：

- Mapbox 需要 access token，前端注入即公开；免费额度按 map load 计费，彩排 + 路演很容易打穿。
- 现场网络对境外 CDN/瓦片并不稳定，Mapbox 挂掉时没有同等级替代。
- MapLibre 的 2D/3D、pitch、fill-extrusion 能力与 Mapbox 同源，OpenFreeMap 提供免费矢量底图，零 key。

结论：先用 MapLibre 把体验做出来；真要用 Mapbox，只需替换 style + token（`window.VTN_MAP_STYLE` 已留接口），不返工。

### 2.2 历史底图 / 年份滑块：本期不做「换底图」✓（但保留年代轴）

LandsD / GeoInfo Map / CSDI 的百年航拍与 TDOP 有三个坑：授权范围、年份覆盖不全、切片与配准工作量大；再加现场网络，四重不确定。**在黑客松舞台上切一张加载不出来的历史底图，比不做更伤。**

所以本期把滑块定义为**故事年代轴**：按 `year ≤ 选中年代` 过滤故事点，标签写「1990 年或以前」，不冒充历史影像。等授权与切片跑通，再把 `VTN_MAP_STYLE` 换成历史栅格源即可，交互不用改。

### 2.3 六类图标 → 七类（补「墟市商贸」）✓

8 则示范故事里，趁墟、米铺、蚝田买卖占了两则。硬塞进「其他」会让地图失去辨识度，而「墟市商贸」正是北区（联和墟、石湖墟）的地方性格。结论：保留 PRD 六类，另加 `market`，`other` 继续兜底；图例只显示有数据的类目，避免空图标。

### 2.4 心情标签：做，但拒绝 AI 推断 ✓

PRD 的「人工勾选、不做 AI 推断」是对的，应该写进数据契约而不是只写在 PRD 里。实现上不再给心情一套独立图标（7 类 × 5 心情 = 35 种组合，必然噪音），而是**颜色角标 + 详情页文字标签**：扫图时几乎无感，打开抽屉才读到「怀旧 / 欢喜 / 沉重」。

当前 8 则故事的 `mood/year` 是团队按逐字稿人工标注的示范数据，已在 `data/stories.json` 顶部注明，不是模型输出。

### 2.5 聚合 + 热力：保留，但把优先级让给单点图标 △

8 个点撑不起「密度热力」叙事，热力很容易变成一团没有信息量的雾。处理方式：

- `zoom < 9.4` 才聚合（数字气泡），放大即展开为单图标；
- 热力仅作低缩放底色（透明度 0.42），不承载读数；
- 默认视野直接显示 8 个单点，优先满足 Douglas 说的「有意思的灵动小图标」。

等故事量上到 50+，再把聚合阈值上调、热力打开成真正的密度层。

### 2.6 二级页：「查看完整故事」不要另开一页 ✓

抽屉本身就是完整故事。再跳一层原详情页，会出现「抽屉 → 页面 → 返回抽屉」的层级回绕。做法：抽屉半开时给摘要 + 播放器，上拉后展开逐字稿与全部操作；路由保持 `#stories?story=YL-001&view=list&since=1990`，分享链接可直接落到故事。

### 2.7 私隐：模糊圈要「看得见」，过滤要「发生在服务端」✓

- 选中故事时绘制 800m 虚线模糊圈，让用户一眼知道这不是精确位置；
- `private` 故事在地图数据源、聚合计数、图例计数、搜索里都不出现；
- 构建期校验 `radiusM ≥ 100`，防止有人「优化」成精确定位。

## 4. 数据契约（已落地）

```json
{
  "storyType": "farming",
  "mood": "wistful",
  "year": 1962,
  "location": { "lat": 22.4445, "lng": 114.0321, "radiusM": 800 }
}
```

- `storyType`：`festival / farming / migration / architecture / oral / market / other`
- `mood`：`wistful / joyful / reflective / heavy / proud`
- `year`：1900–2026 整数；年代轴按它过滤
- 非私人故事必须有香港范围内的坐标与 `radiusM ≥ 100`
