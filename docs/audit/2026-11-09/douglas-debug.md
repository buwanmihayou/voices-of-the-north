## 本次发现并修复

第 4 项的后端集合已共用，但范围仍在以下路径分叉：

- 同一 bbox 的地图返回 3 则故事，`visibleCount` 却为 8，`visibleIds` 也仍含全部故事；问答返回的是裁剪后的 3 则。现在地图元数据也描述实际裁剪后的集合。
- 本机问答只检查授权，忽略地图视口、故事类型和年代等筛选。现在 API 与本机检索共用提问时的故事 ID／视口快照；后端将 ID 选择与授权、撤回、bbox 结果取交集，空选择不会恢复成全库。
- 后端已拒答时，前端仍会再搜本机全库，可能重新引用范围外或服务端已撤回的故事。现在保留服务端故事库拒答；首页对个人录音的独立检索仍保留。无效的混合引用会使整段服务端答案被丢弃，避免只删引用却留下其文字。
- 首页与列表页原本也会附上隐藏地图的旧 bbox。现在只有故事地图模式默认附视口；列表仍使用当前筛选。
- 视口提示原本统计未筛选故事，筛选后也没有立即更新。现在统计实际地图数据并在筛选／移动后更新；Leaflet 回退也提供视口范围。

前端已从 `frontend/src/` 重新构建为交付单文件。
